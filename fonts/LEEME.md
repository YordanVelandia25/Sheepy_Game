# Tipografías

- **Hey Comic** (principal): coloca aquí el archivo con este nombre exacto
  `HeyComic.woff2` (o `HeyComic.otf` / `HeyComic.ttf`). Comprueba que tu licencia
  permita usarla en una web. Mientras falte, el juego usa Lilita One.
- **Century Gothic** (secundaria): se usa si está instalada en el dispositivo
  (Windows y macOS con Office). Si no, se usa Didact Gothic, muy parecida y gratuita.
